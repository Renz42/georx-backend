🛣️ Route Structure

Route Access Description
/ Public Medicine search map (Guest accessible)
/login Guest Only Login page for all users
/register Guest Only User registration
/pharmacy/register Guest Only Pharmacy owner registration
/portal/* Pharmacy Admin Inventory & profile management (own pharmacy only)
/admin/* Super Admin Platform management (all pharmacies & medicines)

✨ Key Features

  • GPS-Enabled Pharmacy Locator with Haversine Formula
  • Real-Time Medicine Inventory Management
  • Role-Based Access Control (RBAC) with 3 User Types
  • Pharmacy Self-Registration with Map Location Picker
  • Medicine Search with Proximity Filtering
  • Scoped Data Access (Pharmacy Admins see only their data)
Tech Stack: Laravel 11 • PHP 8.2 • MySQL • Tailwind CSS • Leaflet.js • Blade Templates
